Drastic Sans

Le comic sans, mais pas sérieux. Une police au feutre, dessinée à neuf. Chaque lettre est tracée trois fois et, dans le texte, les trois versions tournent : les lettres penchent, sautillent et ne tiennent pas en place. 5 graisses, du petit rire au fou rire.

Les graisses

Du petit rire au fou rire : Lol, Mdr, Ptdr, Xptdr et Jpp (« j'en peux plus »). Le dessin ne change pas : seul le feutre s'épaissit, et il triche un peu dans les plus grosses pour garder les signes ouverts.

Testeur

Clique sur le texte pour écrire le tien. Tape ?!, !!, <3 ou wtf pour voir.

Wesh frère, t’as vu ça ?! Sans rire, c’est vraiment drôle <3

Astuce : les 5 graisses sont dans une seule famille « Drastic Sans » : 300, 400, 600, 800 et 900. Les lettres dansent toutes seules (fonction calt) ; Zinzin est ss01 et les cœurs sont ss02.

Caractères

Majuscules, minuscules, chiffres, ponctuation, signes et accents des langues d'Europe en alphabet latin. Et en plus : ‽ ‼ ♥.

D'où elle vient

Un comic sans, en plus vivant. Chaque lettre est écrite à neuf, geste par geste, au feutre : pour les affiches, les bulles, les menus, les invitations, les stories et tout ce qui ne doit pas se prendre au sérieux.

Un feutre qui bave un peu

Une pointe ronde glisse le long de chaque geste. Quand elle se pose, l'encre fait un petit pâté ; quand elle se lève, le trait gonfle à peine ; entre les deux, la main tremble un tout petit peu. Les bols sont des « squircles », ni ronds ni carrés.

Trois versions par lettre

Chaque lettre et chaque chiffre est tracé trois fois. Dans le texte, les trois versions tournent : une penche à gauche et saute, une penche à droite et descend. Deux lettres pareilles côte à côte ne sont jamais identiques.

Mdr, ça dansemmmmmm
Mdr, sans la danse (calt 0)mmmmmm

Zinzin

Avec ss01, les lettres sautent beaucoup plus haut et plus bas. Pour les titres qui crient.

Ptdr (600)Zinzin !!
Ptdr, Zinzin (ss01)Zinzin !!

Des cœurs et des ligatures

?! et !? deviennent un seul signe, !! aussi, <3 devient un cœur et wtf se prend des traits de surprise. Avec ss02, les i et les j ont des cœurs à la place des points.

Mdr (400)?! !? !! <3 wtf
Lol, Cœurs (ss02)bisous, Lili

De Lol à Jpp

Les graisses suivent le rire : Lol, le feutre fin, pour un mot en passant ; Mdr pour lire ; Jpp, le gros feutre, pour ce qui doit se voir de loin.

Installation sur un site web 
@font-face { font-family: "Drastic Sans"; font-weight: 400;
  src: url(DrasticSans-Mdr.woff2) format("woff2"); }
/* … une règle par graisse : Lol 300, Mdr 400, Ptdr 600,
   Xptdr 800, Jpp 900. */
.zinzin { font-feature-settings: "ss01"; }   /* les lettres sautent */
.coeurs { font-feature-settings: "ss02"; }   /* cœurs sur les i et les j */
.sage   { font-feature-settings: "calt" 0; } /* sans la danse */
