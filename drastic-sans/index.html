Drastic Sans

Un comic sans au feutre. Chaque lettre existe en 3 versions qui tournent : le texte danse tout seul. 5 graisses, de Lol à Jpp.

Feutre5 graissesLol → Jpp3 versions par lettreZinzin et cœursLangues d'Europe en alphabet latinUsage personnel gratuitVersion 1.000

Les graisses

Lol, Mdr, Ptdr, Xptdr, Jpp. Plus tu ris, plus c'est gras. Dans les grosses, le feutre triche un peu pour que les lettres restent ouvertes.

Testeur

Clique et écris. Essaie ?!, !!, <3 ou wtf.

LAFLEURSTUDIO création graphique

Une seule famille « Drastic Sans » : 300, 400, 600, 800, 900. La danse, c'est calt. Zinzin, c'est ss01. Les cœurs, ss02.

Caractères

Majuscules, minuscules, chiffres, ponctuation, accents d'Europe. En bonus : ‽ ‼ ♥.

D'où elle vient

Dessinée à neuf, au feutre, geste par geste. Pour les affiches, les menus, les stories. Tout ce qui ne se prend pas au sérieux.

Un feutre qui bave

Pointe ronde. Un pâté d'encre au départ de chaque trait, la main qui tremble un peu. Les ronds ne sont ni ronds ni carrés : des squircles.

3 versions par lettre

Chaque lettre est dessinée 3 fois. Dans le texte, elles tournent : une penche à gauche, une penche à droite, une saute. Jamais deux pareilles côte à côte.

Mdr, ça danseEbenalp
Mdr, sans la danse (calt 0)Ebenalp

Zinzin

Active ss01 : les lettres sautent dans tous les sens. Pour les titres qui crient.

Ptdr (600)Säntis !!
Ptdr, Zinzin (ss01)Säntis !!

Cœurs et ligatures

?!, !? et !! en un seul signe. <3 devient un cœur. wtf se prend des traits de surprise. Avec ss02, des cœurs sur les i et les j.

De Lol à Jpp

Lol pour griffonner, Mdr pour lire, Jpp pour crier.

Installation sur un site web 
@font-face { font-family: "Drastic Sans"; font-weight: 400;
  src: url(DrasticSans-Mdr.woff2) format("woff2"); }
/* … une règle par graisse : Lol 300, Mdr 400, Ptdr 600,
   Xptdr 800, Jpp 900. */
.zinzin { font-feature-settings: "ss01"; }   /* les lettres sautent */
.coeurs { font-feature-settings: "ss02"; }   /* cœurs sur les i et les j */
.sage   { font-feature-settings: "calt" 0; } /* sans la danse */
