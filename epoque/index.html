Les graisses

Sept arrêts, sept endroits du circuit du Bremgarten, à Berne, où se courait le Grand Prix de Suisse. Seul le fût de droite grossit : les filets restent fins. Chaque graisse a sa version Course, penchée de 14°.

Comment on l'a faite

Deux époques dans une lettre. Les années 30 font le corps : le lettrage des affiches de Grand Prix. Les années 50 font la signature : les noms chromés posés sur les carrosseries.

La droite grasse, la gauche en filet

C'est le contraste Art déco. Dans chaque lettre, le trait de droite porte tout le poids. Le trait de gauche et toutes les barres sont des filets. Quand la graisse monte, seule la droite grossit.

Une signature par lettre

Comme sur un emblème chromé, chaque lettre a un petit geste à elle, jamais deux fois le même. A : une aile à gauche. Q : la queue file à l'horizontale. R : la jambe se détache. T : la barre finit en pointe. g : la queue part loin à gauche. i : le point est un trait de vitesse.

Le curseur Vitesse

À 0, la lettre est droite, comme sur le flanc d'un train. À 100, elle penche de 14° vers l'avant et prend un peu d'air, comme sur une affiche de course.

Des tuyaux, pas des découpes

Chaque lettre est une suite de traits avec une épaisseur. Rien n'est découpé après coup : toutes les versions d'une lettre ont les mêmes points. C'est pour ça qu'elle glisse sans accroc d'une graisse et d'une pente à l'autre.
