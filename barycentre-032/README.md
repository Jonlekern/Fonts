# BARYCENTRE-032

Serif de lecture de LaFleurStudio, **dessinée à neuf**. Le centre de gravité est en bas : même trait partout, têtes fines, et le poids tombe dans le bas des courbes, d'un angle à l'autre, en douceur. Le blanc des lettres reste rond.
