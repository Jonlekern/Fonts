# ТРЕНИКИ (TRENIKI)

Calebard qui parle russe. Sans-serif super étendue de LaFleurStudio : le latin de base de Calebard, et un alphabet russe complet dessiné avec les traits de chaque graisse. « Треники », c'est le bas de jogging.

Page : **https://jonlekern.github.io/Fonts/treniki/** (en russe)

## La recette

- **Le latin** : celui de Calebard (A–Z, a–z, chiffres, ponctuation, signes), sans les accents latins : TRENIKI sert à écrire le russe.
- **Le russe** : les 33 lettres, capitales et minuscules, construites graisse par graisse avec les fûts, les barres, les diagonales et les courbes de Calebard.
  - Reprises du latin : А В Е К М Н О Р С Т Х, а е о р с у х.
  - **Л Д** : droits, avec une barre en haut et une jambe en biais. **И** : le N retourné. **Я** : le R retourné. **Ж** : le X et un fût.
  - **Б Ь Ъ Ы** : la boucle du P, à la hauteur des panses du B. **в з б** : le B, le 3 et le 6 ramenés aux minuscules.
  - **Ф** : un fût dans le O. **Э** : le C retourné avec sa barre. **Ю** : un fût, une barre et un O plus étroit. **Ч** : le U remonté.
- **Le crénage** : chaque lettre russe reprend celui d'une lettre latine qui a le même bord. Puis un contrôle compose toutes les paires avec une lettre russe (avec le latin, les chiffres, la ponctuation, et dans tous les contextes de Shatun et Vrazvalku) et écarte celles qui se touchent.
- **L'accent tonique** : l'aigu combinant (U+0301) se pose sur les voyelles russes (моло́ко), aussi dans Shatun et Vrazvalku.
- **Les signes russes** : № ₽ « » „ “ — – … et le trait d'union insécable (U+2011), l'espace fine insécable (U+202F).

### Les deux bonus (base Finish)

| Nom | Effet | Fichier |
| --- | --- | --- |
| Shatun (Шатун, celui qui titube) | Lettres penchées à 12°, une à droite, une à gauche | `TRENIKI-Shatun.ttf` |
| Vrazvalku (Вразвалку, en se dandinant) | Lettres tournées à 4°, 7° et 10°, dans un sens puis dans l'autre | `TRENIKI-Vrazvalku.ttf` |

## Fichiers

- `fonts/ttf/` : les 13 fichiers à installer
- `fonts/woff2/` : les 13 fichiers pour le web
- `TRENIKI.zip` : les 13 fichiers + la licence
- `OFL.txt` : la licence
- `source/` : les scripts. Tout se refait avec `cd source && ./fabrique.sh`, à partir des fichiers de Calebard.
