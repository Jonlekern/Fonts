# ANISOTROPE

Serif de lecture de LaFleurStudio, **dessinée à neuf**. Faible contraste, empattements en coin coupés net, squelette de plume : les ronds penchent, les têtes partent en biais. Pensée pour que tout le monde lise mieux, y compris les lecteurs dyslexiques : **aucune lettre n'est le miroir d'une autre**.

Le nom : un matériau anisotrope n'a pas les mêmes propriétés dans tous les sens. Les lettres non plus.

## La recette

- **Pas de miroir.** b, d, p et q ont chacun leur bas : éperon, coup de pied, pied, coupe en biais. Le u n'est pas un n retourné. Le I a des barres, le l un crochet, le 1 un drapeau.
- **Faible contraste.** Le trait fin fait environ les deux tiers du fût : rien ne disparaît en petit corps.
- **Squelette de plume.** Les ronds penchent de 14°, les têtes des fûts partent en biais vers la gauche, comme une plume large du XVe siècle. C'est le côté vintage.
- **Empattements en coin.** Larges en bas, coupés net, ils rejoignent le fût en biais. C'est le côté futur.
- **De l'air.** Lettres plus espacées qu'à l'ordinaire, contreformes ouvertes (a, c, e), g à un étage.
- **Chiffres.** Petite boucle, long fût. Le 0 est étroit à côtés droits, le 7 est barré, le 3 finit en flèche, le 6 est le 9 retourné.
- **Crénage** automatique par familles : une lettre et ses accents partagent les mêmes paires.

## Caractères

Tout le jeu GF Latin Core : majuscules, minuscules, chiffres, ponctuation, signes et accents des langues d'Europe en alphabet latin. 321 signes.
