# Jalousia

Polices de LaFleurStudio d'après des chiffres romains néo-gothiques dessinés à la main, en deux polices :

- **Jalousia Net** : trait net, rond et régulier ;
- **Jalousia Craie** : le même dessin, au trait de craie (le bord tremble, avec des petits trous et un peu de poussière autour).

Capitales et minuscules, jeu GF Latin Core (langues d'Europe en alphabet latin). Version 1.0.

Page : **https://jonlekern.github.io/Fonts/jalousia/**

## Détails

- Accents combinants placés automatiquement (`mark`, `mkmk`), i et j sans point sous un accent (`ccmp`).
- Ponctuation (tirets, guillemets, points médians) placée pour les minuscules ; la fonction `case` la remonte pour les capitales.
- Espacement : les lettres se glissent les unes sous les autres tant que les traits restent à bonne distance ; les barres de V et W peuvent toucher la lettre d'à côté.
